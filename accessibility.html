Accessibility

Warrior Hub aims to make the resource directory usable with keyboards, screen readers, zoom and reduced-motion preferences.

Current support

  • A skip link moves directly to the resource content.
  • Keyboard focus is visible.
  • Category navigation remains available on small screens.
  • Motion is removed when the browser requests reduced motion.
  • The site does not rely on externally hosted icon fonts.

Report a barrier

Open a public GitHub issue with the page, browser or assistive technology and a description of the barrier. Do not include private information.
