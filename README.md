# Warrior Hub

Warrior Hub is an independent static directory of study, research, campus and wellbeing resources for University of Waterloo students.

Live site: https://hassijatanisha-rgb.github.io/Warrior-hub/

## Verification

Run:

```sh
make check
```

The check validates local links, unique section identifiers, external-link isolation, required disclosure pages, current calendar markers and JavaScript syntax.

## Maintenance

- Review academic dates against the official University of Waterloo Important Dates service before each term.
- Recheck health and emergency descriptions only against official provider pages.
- Treat pricing and access labels as time-sensitive.
- Use GitHub issues for non-confidential corrections.

## Release boundary

GitHub Pages currently publishes the files delivered to a visitor. HTML, CSS and JavaScript on a public static site are inspectable even if a separate source repository is private. Do not describe the delivered frontend as secret or closed source.
